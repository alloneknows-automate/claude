# claude

Günlük kısa bilim videolarının arşivi. Her gün iki video (A ve B) `videos/` klasörüne eklenir.

## Klasör yapısı

```
videos/   Günlük videolar (.mp4)
test/     Bağlantı testi için kullanılan dosyalar
```

## Dosya adlandırma

Videolar şu düzende adlandırılır:

```
YYYY-AA-GG_<A|B>_<konu-kisa-adi>.mp4
```

Örnek: `2026-10-15_A_ay-ayak-izleri-silinmiyor.mp4`

- **Tarih:** videonun yayın günü
- **A / B:** o günün birinci ve ikinci videosu
- **Konu:** Türkçe karakter kullanılmadan, kelimeler tire ile ayrılmış kısa başlık
